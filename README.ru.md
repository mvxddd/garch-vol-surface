Прогнозирует реализованную волатильность моделями семейства GARCH, строит
**безарбитражную поверхность подразумеваемой волатильности** по живым цепочкам
опционов и измеряет зазор между ними — премию за риск волатильности — вместе с
диагностикой, которая позволяет понять, реален ли этот зазор.

```bash
git clone https://github.com/mvxddd/garch-vol-surface && cd garch-vol-surface
pip install -r requirements.txt
python scripts/run_pipeline.py --ticker SPY --lang ru   # полное исследование, ~2 мин
python scripts/run_pipeline.py --provider synthetic     # без интернета
python scripts/run_pipeline.py --snapshot               # ещё и сохранить в историю
streamlit run app.py                                    # веб-интерфейс
pytest -q                                               # 78 тестов, ~12 секунд
```

Результаты ниже — из живого прогона по SPY (2 сентября 2026):
**4 417 сырых котировок → 1 620 чистых подразумеваемых волатильностей по 12
экспирациям**, каждая улыбка откалибрована безарбитражно с точностью
**0.04–0.35 пункта волатильности** относительно середины рынка.

## Дальше одного среза

Базовое исследование описывает одну поверхность за один день. На нём построены
четыре модуля.

### Риск портфеля — `volsurface/portfolio.py`

Принимает позиции (или CSV), оценивает их по откалиброванной поверхности,
собирает греки, раскладывает вегу по срокам и страйкам и строит стресс-сетку
по споту и волатильности:

```python
from volsurface import portfolio as PF
report = PF.risk_report(PF.Portfolio.from_csv("book.csv"), surface)
```

Смысл именно в стресс-сетке: сводка по дельте и веге не показывает гамму и
ванну, и короткий стрэнгл выглядит безобидно в таблице греков ровно до того
момента, когда перестаёт. Как улыбка движется вместе со спотом — явный выбор:
**липкий манинес** (по умолчанию, верно для индексных опционов) или **липкий
страйк**, потому что на большом движении они дают заметно разный P&L.

### История поверхностей — `volsurface/history.py`

Флаг `--snapshot` сохраняет дневную поверхность на фиксированной сетке сроков
(7/30/60/90/180/365 дней — чтобы числа оставались сравнимыми, когда биржевые
экспирации сдвигаются). Когда снимков накопится достаточно, каждая метрика
получает z-оценку относительно **собственного прошлого**, и эти исторические
экстремумы попадают в общий ранжированный список вместе с кросс-секционными.
Меньше 30 снимков — модуль честно не выдаёт ничего вместо бессмысленной оценки.

### Бэктест — `volsurface/backtest.py`

Дельта-хеджированный стрэддл, собирающий премию, с явными издержками.
На живом SPY с 2015 года (139 непересекающихся сделок по 21 дню, вега 10 000,
круговые издержки 1 пункт волатильности):

| Стратегия | Sharpe | Доля прибыльных | Макс. просадка |
|---|---:|---:|---:|
| Всегда шорт волатильности | 0.47 | 78% | −976 тыс. |
| Всегда лонг волатильности | −1.29 | 15% | −4.37 млн |
| Шорт только когда премия богата (z > 0.5) | **1.55** | 83% | **−155 тыс.** |

Кривая «всегда шорт» — классическая форма короткой волатильности: медленный
подъём и обрыв в феврале 2020-го, где одна сделка съела 15 средних выигрышей.
Тайминг по премии примерно утраивает Sharpe и уменьшает просадку на 84% —
и это тот результат, ради которого имеет смысл считать премию за риск.

**Чего здесь сознательно нет:** бэктеста отдельных страйков по сегодняшней
цепочке. Истории цен опционов в бесплатных данных нет, поэтому такой «бэктест»
переоценивал бы прошлое сегодняшней поверхностью — заглядывание в будущее,
которое гарантирует красивую кривую капитала. Вместо этого `signal_backtest`
проигрывает реальную историю снимков и отказывается работать на базе моложе
60 дней.

### Веб-интерфейс — `app.py`

`streamlit run app.py`: выбрать актив, нажать кнопку — и получить все семь
вкладок (поверхность, прогноз, премия, скрин, риск портфеля, бэктест, данные)
на любом из двух языков. При загрузке страницы ничего не считается (построение
поверхности бьёт в источник с лимитом запросов), результаты кэшируются по
параметрам.

## 1. О проекте

Два вопроса, которые обычно изучают порознь, здесь сведены вместе.

**Какой будет волатильность?** Модели семейства GARCH оцениваются методом
максимального правдоподобия по дневным логарифмическим доходностям,
отбираются по BIC и — это главное — проверяются **вне выборки** процедурой
walk-forward: против реализованной волатильности и против наивных бенчмарков,
которые они обязаны обыграть, чтобы оправдать свою сложность.

**Во сколько волатильность оценивает рынок?** Полная цепочка опционов по всем
страйкам и срокам очищается, переводится в подразумеваемую волатильность через
модель Блэка-76 на форвардах из паритета пут-колл и калибруется в поверхность
raw-SVI при явных ограничениях на отсутствие арбитража.

**Разница между ними — это и есть суть.** Подразумеваемая волатильность ATM
минус прогноз GARCH, сопоставленные по горизонту, дают премию за риск
волатильности. А места, где поверхность противоречит **сама себе**, попадают в
скрин относительной стоимости.

Чем это отличается от учебного упражнения:

- **Форварды из паритета пут-колл**, а не из угаданной дивидендной доходности.
  Ошибка в форварде на 0.3% создаёт около 1 пункта фальшивого скью — больше,
  чем большинство эффектов, которые мы измеряем.
- **Ограничения на арбитраж не проверяются, а навязываются.** SVI калибруется
  при условии Дюрлемана, поэтому подогнанная плотность не может уйти в минус.
- **Вне выборки по построению**, с тестами Диболда-Мариано и стандартными
  ошибками Ньюи-Уэста: перекрывающиеся окна прогноза раздувают наивную
  t-статистику примерно в √h раз.
- **Пайплайн отчитывается о том, что выбросил.** Воронка качества котировок
  считает каждый фильтр, поэтому происхождение поверхности можно проверить.

## 2. Зачем это на реальном рынке

| Деск | Как используется |
|---|---|
| **Маркет-мейкинг опционов** | Поверхность *и есть* движок ценообразования. Котировки выставляются по откалиброванной улыбке, а не по отдельным контрактам, чтобы каждый страйк был согласован с соседями и книгу нельзя было выбить на бабочке. |
| **Арбитраж волатильности** | Премия за риск — базовая сделка кэрри: продать опционы, дельта-хеджировать, собрать премию. Размер позиции зависит от того, дорога сегодняшняя премия или дешева относительно собственной истории. |
| **Риск-менеджмент деривативов** | Греки имеют смысл только на гладкой безарбитражной поверхности. Вега-лестницы, риск скью и календарный риск читаются именно с неё. |
| **Структурные продукты** | Экзотике нужна полная поверхность как граничное условие для модели локальной или стохастической волатильности. Арбитражная поверхность даёт модель, которую невозможно откалибровать. |
| **Хеджирование портфеля** | 25-дельтовый risk reversal — прямая цена защиты от обвала; временная структура подсказывает, покупать её на коротком или длинном сроке. |

Два вывода из живого прогона, показывающие, зачем нужна диагностика:

- **Историческая премия реальна.** VIX против впоследствии реализованной
  волатильности, 1 906 перекрывающихся наблюдений: среднее **+3.96 пункта**,
  положительна в **84.7%** дней, t-статистика Ньюи-Уэста = **7.5**. Худшее
  единичное наблюдение — **−66 пунктов**: премия существует именно потому, что
  продавцов изредка разносит.
- **Текущий срез — наоборот.** Подразумеваемая на 30 дней 12.3% против прогноза
  GARCH 14.6%: премия **отрицательная**, −2.3 пункта. Реализованная
  волатильность только что схлопнулась, а модель ещё возвращалась к среднему
  снизу вверх. Исследование, которое показало бы только долгосрочное среднее,
  упустило бы состояние, в котором рынок находится сейчас.

```
                    │            svi ─────────── улыбка        │
                    │            surface ─────── запрос (k,T)  │
                    │      │                                   │
                    │      ▼                                   │

                    │      │                                   │
                    │      ▼                                   │
                    │  i18n.py   каталог строк (en / ru)       │
                    │  viz/      тема · графики                │
                    │      │                                   │
                    │      ▼                                   │
                    │  pipeline.py ── изоляция стадий          │
                    └──────────────────────────────────────────┘
                           │                    │
                    outputs/reports/*.csv   outputs/figures/*
```

**Правило слоёв:** каждый слой импортирует только те, что выше.
`analytics` не знает о провайдерах данных, `models` не знает, что такое
провайдер. Поэтому переход с Yahoo на Polygon — изменение одной строки
конфига, а не переписывание.

**Изоляция стадий.** Моделирование волатильности и построение поверхности —
независимые задачи, у которых просто общий базовый актив. Если в выходные
отвалится фид опционов, половина с GARCH всё равно отработает и выдаст отчёт:
пайплайн записывает статус по каждой стадии, а не падает целиком. Это покрыто
тестом, а не декларацией.

## 4. Источники данных

| Источник | Что даёт | Стоимость | Примечания |
|---|---|---|---|
| **Yahoo Finance** (`yfinance`) | Дневные OHLCV, цепочки опционов, история VIX/VXN/RVX | Бесплатно | По умолчанию. Ограничивает частоту запросов и иногда отдаёт пустые таблицы — отсюда повторные попытки и кэш. Bid/ask устаревает вне основной сессии. |
| **Polygon.io** | Котировки NBBO, надёжный открытый интерес, исторические цепочки | Платно | Рекомендуемый апгрейд и единственный реальный путь к *истории* поверхностей. |
| **Синтетический генератор** | Доходности с кластеризацией + безарбитражная SVI-цепочка | Бесплатно | Не игрушка: цены строятся из корректных параметров SVI, поэтому калибровка проверяется «туда и обратно». |
| **FRED / Казначейство** | Кривая безрисковой ставки | Бесплатно | Опционально; форвард из паритета и так поглощает большую часть неточности в ставке. |

**Оговорки, которые стоит знать до того, как доверять результату:**

- Котировки Yahoo — это снимки, и они **не одновременны по разным
  экспирациям**, что порождает мелкие календарные нарушения. Живой прогон
  отметил два, оба меньше 0.003 в полной дисперсии.
- Открытый интерес обновляется раз в сутки, до открытия.
- Биржевые опционы на акции **американские**, а здесь считаются европейскими.
  Для опционов вне денег на индекс с малыми дивидендами смещение мало, но не
  равно нулю.

## 7. Порядок сборки

Собирать в таком порядке; каждый шаг проверяем до того, как от него зависит
следующий.

1. **Сначала ядро ценообразования.** Блэк-76 на форвардах, греки,
   векторизованный расчёт IV. *Проверка:* паритет пут-колл до 1e-12, вега
   против конечной разности, цикл цена→IV→цена на 50 000 случайных контрактов.
2. **Синтетические данные.** Доходности из рекурсии GJR-GARCH, цепочка из
   *корректных* параметров SVI. Это стоит сделать до подключения реального API:
   появляется эталон для тестов, и всё дальнейшее можно отлаживать офлайн.
3. **Загрузка и очистка.** Повторы, кэш, воронка котировок, форварды из
   паритета, отбор опционов вне денег, расчёт IV. *Проверка:* полученные IV
   совпадают с синтетическим эталоном с точностью лучше 0.05 пункта.
4. **GARCH.** Оценить набор моделей, выбрать по BIC, построить прогнозную
   кривую. *Проверка:* персистентность в (0.8, 1.0), прогнозы сходятся к
   долгосрочному уровню. **Осторожно:** свободный член EGARCH живёт в
   *логарифме* дисперсии — если прочитать его наивно, получится долгосрочная
   волатильность 0.00002%.
5. **Валидация walk-forward.** Расширяющееся окно, переоценка раз в месяц,
   между переоценками — фильтрация вперёд. *Проверка:* целевая будущая
   реализованная волатильность использует только доходности строго после даты
   решения. Эта ошибка подглядывания — самый частый способ получить фиктивное
   качество прогноза.
6. **Калибровка SVI.** Мультистарт наименьших квадратов с ограничениями в виде
   штрафов. *Проверка:* подогнать SVI к ценам, сгенерированным из SVI, и
   получить исходные параметры обратно.
7. **Сборка поверхности.** Интерполировать **полную дисперсию** линейно по T.
   *Проверка:* полная дисперсия не убывает по T при любом лог-манинес.
8. **Аналитика, потом графики, потом пайплайн.** Тема раньше графиков;
   обработка ошибок по стадиям при сборке воедино.

### Три ошибки, которые стоили больше всего времени

- **Интерполяция подразумеваемой волатильности по срокам вместо полной
  дисперсии.** Выглядит нормально и тихо создаёт бесплатные календарные спреды
  между биржевыми экспирациями.
- **Робастная функция потерь, которая заодно давит штрафы за ограничения.**
  Ранняя версия калибровки SVI использовала `soft_l1` по общему вектору
  невязок — и молча выдавала арбитражные улыбки, потому что штрафы обрезались
  вместе с выбросами. Робастность и ограничения должны быть разными
  механизмами.
- **Фиксированный диапазон страйков вместо реальной цепочки.** Биржа котирует
  страйки в масштабе σ√T. Фиксированные ±30% просят двухнедельный опцион на 30%
  вне денег и получают «подразумеваемую волатильность» 250%, которую никто
  никогда не котировал.

## 8. Сбор данных

```
load_prices ──► повтор(3, экспоненциальная пауза) ──► кэш parquet (12 ч)
                                                       │
                                                       ├─ сбой провайдера
                                                       ▼
                                          синтетика (с громким предупреждением)
```

- **Отбор экспираций** логарифмически равномерен по срокам — плотно на ближнем
  конце, где кривая живёт, и редко на дальнем, — а не «первые N подряд».
- **Кэш** ключуется по хешу параметров запроса, TTL 12 часов для цепочек.
  Сбой чтения кэша приводит к перезагрузке, сбой записи не ломает прогон.
- **Признак синтетики** проходит через весь пайплайн, поэтому смоделированные
  данные невозможно молча выдать за рыночные.

## 9. Очистка и признаки

Воронка из живого прогона по SPY:

| Стадия | Котировок | Осталось |
|---|---:|---:|
| Сырые | 4 417 | 100% |
| Корректная цена и страйк, без дублей | 4 417 | 100% |
| Bid ≥ 0.05 | 3 937 | 89.1% |
| Относительный спред ≤ 35% | 3 937 | 89.1% |
| Открытый интерес ≥ 10 или были сделки | 3 739 | 84.7% |
| Манинес K/F ∈ [0.70, 1.30] | 2 960 | 67.0% |
| Только вне денег | 1 620 | 36.7% |
| IV успешно посчитана | 1 620 | 36.7% |

**Зачем каждый фильтр**

- *Никаких нулевых bid.* У рынка 0 × 0.05 «середина» равна 0.025, по которой
  никто не торгует, и полученная из неё волатильность — чистая выдумка.
- *Только вне денег.* Опционы в деньгах несут ту же информацию о волатильности,
  но гораздо больше внутренней стоимости, поэтому тот же спред в долларах даёт
  куда большую ошибку в волатильности.
- *Идентифицируемость по веге.* Расчёт возвращает NaN — а не догадку, — если
  вега в точке решения ниже порога. Там цена не зависит от σ в пределах
  точности double, и «корень» был бы шумом.

**Инженерные признаки**

| Признак | Определение | Зачем |
|---|---|---|
| `forward` | регрессия C−P на K из паритета | поглощает дивиденды и фондирование без угадывания `q` |
| `k` | log(K/F) | естественная ось улыбки, сравнимая между сроками |
| `total_variance` | IV²·T | величина, которая обязана монотонно расти по T |
| `vega` | Блэк-76 | вес калибровки: подгоняем то, чем реально торгуют |
| `iv_bid`, `iv_ask` | IV из bid и ask | спред **в пунктах волатильности** — единственная шкала, на которой видно, торгуем ли сигнал |

## 10. Модели и алгоритмы

### Расчёт подразумеваемой волатильности

Защищённый метод Ньютона с поддерживаемой вилкой бисекции, полностью
векторизованный. Чистый Ньютон расходится в крыльях, где вега → 0; чистый Брент
примерно в 50 раз медленнее на цепочке из 5 000 котировок.
**50 000 расчётов за 66 мс, медианная ошибка 2e-14.** Цены за пределами
статических безарбитражных границ отбраковываются сразу.

### Семейство GARCH

```
σ²ₜ = ω + (α + γ·1{rₜ₋₁<0})·r²ₜ₋₁ + β·σ²ₜ₋₁
```

Четыре спецификации (нормальная, стьюдента, GJR-t, EGARCH-skew-t), отбор по
BIC, оценка по доходностям, умноженным на 100: MLE на десятичных доходностях
плохо обусловлен и регулярно застревает. Многошаговые прогнозы аналитические
там, где это возможно, и симуляционные для EGARCH. При агрегировании по
горизонту усредняется **дисперсия**, а не волатильность, потому что опцион
оценивается по ожидаемой интегральной дисперсии до экспирации.

### Raw SVI

```
w(k) = a + b[ ρ(k−m) + √((k−m)² + σ²) ],    w = IV²·T
```

Калибруется мультистартом наименьших квадратов с тремя ограничениями,
добавленными прямо в вектор невязок: минимальная полная дисперсия
`a + bσ√(1−ρ²) ≥ 0`; граница крыльев Ли `b(1+|ρ|) ≤ 4/T`; условие Дюрлемана
`g(k) ≥ 0` на плотной сетке, эквивалентное неотрицательности риск-нейтральной
плотности. Вес штрафа наращивается, пока ограничения не начнут работать, плюс
один проход перевзвешивания для выбросов.

**Проверка «туда и обратно»:** подгонка SVI к ценам, сгенерированным из SVI,
восстанавливает ρ с точностью до третьего знака и b до четвёртого.

### Интерполяция поверхности

Линейно по **полной дисперсии** относительно T между откалиброванными срезами.
На коротком конце волатильность держится постоянной, на длинном — форвардная
дисперсия. Монотонность по T проверена на всей сетке: именно это свойство
делает интерполированную поверхность свободной от календарного арбитража.

## 11. Графики

15 фигур на одной палитре, проверенной валидатором цветовосприятия, а не
подобранной на глаз. Три правила по всем графикам:

- **Никогда две шкалы Y.** Две величины разного масштаба — это две панели,
  а не вторая ось: вторая ось позволяет автору выбрать ту корреляцию, которую
  увидит читатель.
- **Упорядоченному — упорядоченная шкала, сущностям — категориальные цвета.**
  Срок упорядочен, поэтому сроки идут от светлого к тёмному. Модели — это
  сущности, у них фиксированные цвета.
- **Легенда плюс прямые подписи на каждом многосерийном графике**, чтобы цвет
  никогда не был единственным носителем смысла.

Графики поверхности **закрашивают область за пределами котируемых страйков** на
каждом сроке. Двухнедельный опцион не котируется на 30% вне денег, и раскрасить
этот угол как подогнанные данные — самое вводящее в заблуждение, что может
сделать график поверхности.

## 12. Метрики

### Прогноз волатильности

| Метрика | Что ловит |
|---|---|
| **QLIKE** | Основная метрика ранжирования. Устойчива к шуму в оценке реализованной дисперсии и штрафует **занижение** прогноза гораздо сильнее — правильная асимметрия для того, кто в короткой позиции по опционам. |
| **Минцера-Зарновица** | β < 1 — классический признак того, что GARCH переоценивает реакцию. Приводится с t-тестом на β = 1. |
| **RMSE / MAE** | Понятны в пунктах волатильности, но их определяют несколько взрывных дней. |
| **Диболда-Мариано** | Реальна ли разница в ранжировании. Долгосрочная дисперсия по Ньюи-Уэсту плюс поправка Харви на малую выборку. |
| **Бенчмарки** | Историческая волатильность за 21 день и EWMA(0.94) по RiskMetrics. GARCH, который не обыгрывает EWMA, не оправдывает своей сложности. |

Живой SPY, горизонт 1 день: все спецификации GARCH обыгрывают оба бенчмарка по
QLIKE, тесты Диболда-Мариано подтверждают значимость на уровне 5%. R²
относительно реализованной волатильности — 5–20%: это норма, а не провал.

### Калибровка поверхности

| Метрика | Результат по живому SPY |
|---|---|
| RMSE подгонки по экспирациям | 0.04 – 0.35 пункта волатильности |
| Смещение по экспирациям | ≤ 0.08 пункта, без систематического знака |
| Срезов без арбитража на бабочке | 12 / 12 |
| Календарных нарушений | 2, оба < 0.003 в полной дисперсии |
| Модель внутри рыночного bid/ask | 13 – 45% по экспирациям |

Последняя строка выглядит как провал, но им не является. Опционы на SPY часто
котируются с шириной в один цент, что при таких премиях составляет доли пункта
волатильности — теснее, чем невязка 0.04–0.35 пункта у пятипараметрической
улыбки, подогнанной по сотне с лишним страйков. На синтетическом контроле с
реалистично широкими спредами тот же код даёт **100%**. Честный вывод:
подгонка отличная в абсолютных величинах, но на SPY её всё равно недостаточно,
чтобы торговать отдельный страйк против улыбки без модели транзакционных
издержек. Именно поэтому скрин аномалий измеряет невязки **в долях половины
спреда**, а не в пунктах волатильности.

## 15. Куда развивать

**Модели**

- **Американское исполнение** через биномиальную схему, PDE или приближение
  Барона-Адези-Уэйли — снимает главное структурное смещение для отдельных акций.
- **HAR-RV на внутридневных данных.** На пятиминутках модели реализованной
  волатильности регулярно обыгрывают GARCH на горизонтах больше дня.
- **Калибровка стохастической волатильности** (Хестон, SABR, rough Bergomi) по
  всей поверхности — динамическая модель вместо статического среза.
- **SSVI / eSSVI:** совместная калибровка всех сроков, чтобы отсутствие
  календарного арбитража следовало из построения, а не проверялось после.

**Данные и инфраструктура**

- **Исторические цепочки Polygon** → *история* поверхностей, которая превращает
  скрин из кросс-секционного во временной.
- **Согласование меток времени** полностью убрало бы ложные календарные
  нарушения.
- **Ежедневное сохранение** плюс планировщик — поверхность становится
  наблюдаемым активом, а не разовым срезом.
- **Календари отчётностей и дивидендов**, чтобы автоматически объяснять изломы
  временной структуры.

**Торговля**

- **Бэктест сигналов.** Каждую находку скрина нужно проверить как
  дельта-хеджированную позицию с учётом издержек. Без этого скрин порождает
  гипотезы, а не стратегию.
- **Построение портфеля по веге** с лимитами на суммарную вегу, скью и
  календарную экспозицию.
